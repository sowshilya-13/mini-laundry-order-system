# Mini Laundry Order Management System

## Project Overview
This is a simple Laundry Order Management System built using Flask. It helps a dry cleaning store manage orders, billing, and status tracking.

## Features
- Create Order
- Generate Unique Order ID
- Calculate Billing
- Update Order Status
- View Orders
- Search and Filter Orders
- Dashboard (Total Orders, Revenue, Status Count)
- Delete Order
- Estimated Delivery Date
- SQLite Database

## Tech Stack
- Python
- Flask
- HTML
- SQLite

## Setup Instructions

### Install dependencies
pip install -r requirements.txt

### Run the project
python3 app.py

### Open in browser
http://127.0.0.1:5001
